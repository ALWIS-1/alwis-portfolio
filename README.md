# ALWIS Portfolio

A responsive, static portfolio website for GANZA Nyirikunda Alwis.

## Preview locally

1. Extract the folder if you downloaded the ZIP.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish online

This is a static website and can be hosted on GitHub Pages, Netlify, or Vercel. Upload the complete folder contents; keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together. No build step or backend is required.

## Personal details to review before publishing

Check the email, phone number, Instagram link, school name, and project descriptions in `index.html`. The VaultChain description is intentionally marked as awaiting details because its features and purpose have not yet been confirmed in this portfolio draft.
